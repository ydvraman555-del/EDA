# Exploratory Data Analysis (EDA) Project

## Overview
This project focuses on performing Exploratory Data Analysis (EDA) using Python to understand data distributions, relationships, and patterns through statistical analysis and visualizations.

## Project Structure

- EDA Project on Rohit Sharma.ipynb
- README.md

Source: Kaggle / Public dataset  
Domain: Sports Analytics (Cricket – Player Performance)

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## EDA Performed
- Data cleaning and preprocessing
- Handling missing values
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Data visualization

## Key Insights
- Performance trends across matches
- Distribution of important numerical features
- Relationships between performance metrics
- Identification of outliers and patterns
