# Exploratory Data Analysis (EDA) Projects

This repository contains multiple **Exploratory Data Analysis (EDA)** projects performed on different datasets. The objective of these projects is to explore datasets, clean data, identify patterns, and generate insights using Python data analysis libraries.

These projects demonstrate practical skills in **data cleaning, visualization, statistical analysis, and feature understanding**, which are essential in data science and data analytics.

---

## Projects Included

### 1. Titanic Dataset EDA
Analysis of the famous Titanic dataset to understand survival patterns among passengers.

Key Analysis:
- Survival rate based on gender
- Survival rate based on passenger class
- Age distribution of passengers
- Feature correlation analysis

---


### 2. Rohit Sharma Performance Analysis
EDA performed on a dataset related to Rohit Sharma's cricket performance.

Key Analysis:
- Runs scored across matches
- Performance trends over time
- Comparative match statistics

---

### 3. Sleep Disorder EDA
Exploratory analysis of a sleep health dataset to understand factors influencing sleep disorders.

Key Analysis:
- Sleep duration vs health indicators
- Distribution of sleep disorders
- Lifestyle factors affecting sleep quality
